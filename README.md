 # Smart Home – M5Stack MicroPython

Project Overview

This repository contains the MicroPython source code for the M5Stack component of the Smart Home system.
The M5Stack device is used to detect motion, read environmental sensor values, and communicate with the Smart Home application using MQTT.

The M5Stack program was done using Blockly in UIFlow, which automatically generated the corresponding MicroPython code. 
However, I later modified and extended the generated Python code manually. This allowed me to make more specific adjustments to the complex MQTT communication and the sensors handling without having to recreate or rearrange multiple Blockly blocks.
